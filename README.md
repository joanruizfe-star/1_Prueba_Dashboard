# 1_Prueba_Dashboard
Prueba de Dashboards


DESCRIPCION

Crear un Dashboard sobre una BBDD descargada en línea.


ESTRUCTURA DEL PROYECTO

Carpeta 1.- Datos EDA -> Contiene la BBDD original en la que se centra el Dashboard.
Carpeta 2.- URL Datos EDA -> URL donde se ha descargado la BBDD.
Carpeta 3.- Proyecto -> Contiene el GoogleSheets descargado con el proyecto.
Readme.md -> Descripción del proyecto


INSTALACIÓN Y REQUISITOS

Este proyecto solo necesita GoogleSheets o Excel para hacer el proyecto.
